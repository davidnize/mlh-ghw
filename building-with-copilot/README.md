# The Tiny Adventure

A very simple choose-your-own-adventure game written in Python. Pick a path through the forest and see where the story takes you.

## Run the game

1. Make sure Python 3 is installed.
2. Open a terminal in the folder containing `adventure.py`.
3. Run:

   ```bash
   python3 adventure.py
   ```

When the game shows numbered choices, enter a number and press Enter.
