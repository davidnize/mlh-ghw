# MLH Global Hack Week: Builders Week 🛠️

My projects and challenge submissions from MLH Global Hack Week: Builders Week (2026).

## Projects

- **intro-to-github**: GitHub Skills exercise on repos, branches, commits and pull requests (Introduction to GitHub).
- **code-with-codespaces**: GitHub Skills exercise on coding in a cloud dev environment (Code with Codespaces).
- **intro-to-repository-management**: GitHub Skills exercise on managing a repository (Intro to Repository Management).
- **getting-started-with-copilot**: GitHub Skills exercise on getting started with GitHub Copilot.
- **building-with-copilot**: A small app built with GitHub Copilot (Use GitHub Copilot to Build a Simple Application).
- **mini-app-with-cursor**: A small working app built from scratch with Cursor (Challenge 1: Build a Mini App with Cursor).
- **auth0-login-flow**: A web app with Auth0 login and logout (Set up your first Auth0 log-in flow).
- **auth0-context-assistant**: A full-stack personal assistant using Auth0 for identity and API access (The Context-Preserving Assistant).

## Built with
JavaScript, Node.js, Express, Auth0, GitHub Copilot and Cursor.
